# Системные утилиты для Windows

Набор из проектов работы с системными механизмами ОС Windows (версии 7–11).

## ConsoleApplication1: Файловый сервер на базе RPC

**Описание:**
Клиент-серверное приложение для предоставления удаленного доступа к файловой системе сервера. Взаимодействие реализуется через механизм удаленного вызова процедур (RPC).

**Реализация:**
- Stateful сервер без интерактивного интерфейса (работает в фоне).
- Описание контракта выполнено в IDL-файле, скомпилировано через MIDL (сгенерированы файлы **RPS_s.c**, **RPS_h.h**, **RPS_c.c**). Уникальная идентификация через UUID.
- Имперсонация клиента на стороне сервера (используются функции **LogonUserA** и **ImpersonateLoggedOnUser**). Демонстрирует корректную работу механизмов контроля доступа как при повышении, так и при понижении прав потока относительно процесса сервера.
- Копирование файла с клиента на сервер, загрузка файла с сервера, удаление файла на сервере. Поддержка путей в формате UNC.

## ConsoleApplication2: Служба резервного копирования (Backup Service)

**Описание:**
Программа функционирует как служба Windows (интеграция с SCM) и осуществляет автоматическое резервное копирование данных из указанной директории в ZIP-архив.

**Реализация:**
- Неинтерактивная работа. Все параметры задаются через конфигурационный файл (исходная директория, путь к архиву, маски файлов).
- Создание и обновление ZIP-архивов с использованием библиотек **bz2.dll**, **zip.dll**, **zlib1.dll**.
- Автоматическое отслеживание изменений или появления новых файлов по маскам (символы ***** и **?**) с сохранением структуры вложенности папок.
- Реализован собственный SCP (Service Control Program) для инсталляции, деинсталляции, запуска и остановки из командной строки. Корректная обработка команд от оснастки "Службы".
- Поддержка имен файлов и директорий в формате UNC.

## ConsoleApplication3: Менеджер учетных записей и привилегий

**Описание:**
Консольная утилита для управления пользователями, локальными группами и политиками безопасности в ОС Windows с прямым вызовом низкоуровневых API.

**Реализация:**
- Функции API загружаются во время выполнения через **LoadLibrary** и **GetProcAddress** (библиотеки **netapi32.dll** и **advapi32.dll**).
- Вывод списков пользователей и групп с их идентификаторами безопасности (SID) и назначенными привилегиями.
- Добавление, изменение и удаление пользователей (**NetUserAdd**, **NetUserDel**) и групп (**NetLocalGroupAdd**, **NetLocalGroupDel**). Управление членством в группах.
- Назначение и отзыв привилегий (например, **SeDebugPrivilege**, **SeShutdownPrivilege**) через механизмы LSA (**LsaAddAccountRights**, **LsaRemoveAccountRights**). Демонстрация наследования привилегий при добавлении пользователя в группу.
- Основная логика реализована в **StartMenu.cpp** и **StartMenu.h**.

## ConsoleApplication4: Монитор безопасности и планировщик задач

**Описание:**
Инструмент для управления системными задачами и настройками безопасности среды Windows. Взаимодействует с планировщиком задач и брандмауэром через COM-интерфейсы.

**Реализация:**
- Вывод списка всех активных задач и их статуса (рекурсивный обход папок через **ITaskService**). Создание и удаление задач.
- Создание правил, отслеживающих события изменения настроек встроенного антивируса Windows Defender и Брандмауэра (генерация уведомлений через вспомогательный модуль **Message_task.exe**).
- Блокировка входящих ICMP-запросов (ping) с заданного IP-адреса через **INetFwPolicy2**.
- Отслеживание события блокировки пакетов (Event ID 5152) и вывод графического уведомления оператору.
- Консольное управление командами.

## Требования к среде выполнения

Для сборки и тестирования проектов применялся следующий стенд:
- **ОС:** Windows 10 (поддерживается диапазон Windows 7–11).
- **Инструментарий:** Visual Studio 2022, Microsoft SDK, компилятор MIDL.
- **Сетевое взаимодействие:** Для тестирования RPC (App1) и блокировки ICMP (App4) использовались две машины (Сервер на Windows 10 и Клиент на Windows 10 / Kali Linux).
- **Права:** Для работы с привилегиями (App3) и системными службами/брандмауэром (App2, App4) требуются права администратора.

## Примеры использования и команды

Для управления сервисом резервного копирования (ConsoleApplication2):

```
# Установка службы в систему
ConsoleApplication2.exe install

# Запуск службы
ConsoleApplication2.exe start

# Остановка службы
ConsoleApplication2.exe stop

# Удаление службы из системы
ConsoleApplication2.exe uninstall
```

Для работы с монитором безопасности и планировщиком (ConsoleApplication4):

```
# Вывод списка задач планировщика
ConsoleApplication4.exe list

# Создание правил мониторинга изменений (Defender и Брандмауэр)
ConsoleApplication4.exe changes

# Создание правила блокировки ICMP (ping) с указанного IP
ConsoleApplication4.exe block:192.168.1.71
```

Для включения аудита отбрасывания пакетов (необходимо для фиксации события 5152 в App4):

```
auditpol /set /subcategory:"Отбрасывание пакета платформой фильтрации" /failure:enable
```
